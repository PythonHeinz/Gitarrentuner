# Einen neuen Strang starten

Die Projektanweisung im Claude-Projekt trägt alles, was ein Strang zum Start braucht. Der Entwickler muss nur:

1. In der Claude-App im Projekt „Gitarren Heinz“ einen **neuen Chat** öffnen.
2. Als ersten Satz den **Strangnamen** nennen, zum Beispiel `GitarrenHeinz-Audio`. Namen und Reihenfolge stehen im Register „Stränge“ in `STAND.md`; der Auftrag liegt als `AUFTRAG_<Strang>.md` in diesem Ordner (legt der Root an).
3. Sagen, ob der Strang schon bauen darf. Der Strang prüft „Aktive Arbeit“ selbst und fragt bei Zweifel.

Dem Chat zuerst geben: Desktop-Verbindung und Zugriff auf den Ordner `Toolsbyclaude`, sobald Dateien am PC gebraucht werden. Das Repo hängt der Strang selbst an.
