# Gitarrentuner

Einfacher Gitarrentuner für sechssaitige Gitarren als Web-App (HTML, für Smartphone/Android, Design im Stil von Braun und frühem Apple). Spätere Ausbaustufen: Ukulele und weitere Instrumente.

Projektsteuerung (Stränge, Stand, Routine): `docs/agent/`. Start: `docs/agent/UEBERGABE.md`, Stand: `docs/agent/STAND.md`.
